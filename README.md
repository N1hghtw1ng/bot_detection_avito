# Bot Detection Solution

Это решение задачи выявления ботов по логам активности.
Оно переработано на основе аудита:
1. Выполнено в виде единого, понятного Jupyter Notebook (`solution.ipynb`).
2. Включает корректную фильтрацию событий (исключение будущих событий) и удаление полных дублей.
3. Содержит 20 объяснимых агрегированных признаков (с фокусом на временные характеристики).
4. Обучает модель LightGBM, оценивая ее на 3 временных сплитах.
5. Формирует правильный файл `submission.csv` со всеми необходимыми проверками целостности.

## Ограничения
- Использованы только open-source библиотеки локально.
- Внешние API или большие языковые модели не применялись.
- Решение не предназначено для автоматической блокировки в production "как есть", а лишь максимизирует метрику `P@R>=0.7` на предоставленных тестовых данных.

## Воспроизводимость
Версия Python: `3.12`
Для установки зависимостей:
```bash
pip install -r requirements.txt
```

Использованные open-source библиотеки: `pandas`, `numpy`, `scikit-learn`, `lightgbm`.

## Запуск
Просто откройте `solution.ipynb` в Jupyter Notebook / JupyterLab / VSCode и выполните все ячейки. На выходе будет сформирован файл `submission.csv`.
